# Exodus Venue

A professional, real-time visitor flow monitoring and reporting tool. Designed for venue supervisors to track headcount and safety limits with ease.

## 🚀 Live Demo
**[View the Live Web App](https://RobiTobiGoGetGo.github.io/exodus_venue/)**

## ✨ Features
* **Dual Counting**: Track "Total Entered" and "Still Inside" simultaneously.
* **Visual Safety Indicators**: Automatic "heat-map" warnings as you approach capacity.
* **Multiple Input Modes**: Switch between Button mode and high-speed Gesture (swipe) mode.
* **Professional Reporting**: Export logs as formatted PDF or CSV reports directly from the browser.
* **Progressive Web App**: Can be "installed" on mobile devices via Edge or Chrome.

## 📱 Platforms
* **Web**: Fully optimized for Microsoft Edge and modern browsers.
* **Android**: Native support with haptic feedback.
